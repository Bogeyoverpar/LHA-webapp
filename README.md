# LHA League Manager v2.3
Adds:
- playoff series dropdowns with all seven games
- automatic home pattern: higher seed G1-2, lower seed G3-5, higher seed G6-7
- Regular / Playoffs / Combined stat views
- permanent PlayerID on imports and automatic migration of loaded roster state
- Transactions & Honors: trade/transfer, call up, send down, release
- transaction history
- All-Star and All-Season selections
- existing game editing, standings, overrides and JSON backup remain

Storage is still session state by design while the program is being stabilized.
