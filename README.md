# LHA / MLH League Manager v2.4
MLH is integrated into the same interface as the LHA. The league-view switch applies to games, standings, statistics, teams, game logs, playoffs, and honors. Shared affiliate relationships drive call-ups and send-downs while PlayerID remains constant across levels.

## v2.5
- Canonical full MLH franchise names throughout the app.
- Automatic migration of early v2.4 city-only MLH records.
- Team-page logo upload and display; logo data is retained in JSON backups.
- Team history fields: Championships, Division Titles, Retired Numbers, Other Team Honors.
- Visual playoff brackets for both LHA and MLH, while retaining detailed series/game entry.
- Schedule import rejects unknown team names instead of silently accepting mismatches.
