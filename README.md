# LHA League Manager v2.3.3

Adds Team Center:
- Select any of the 12 LHA teams.
- Current division rank, record, points, goal differential, games remaining and playoff status.
- Editable head coach, GM/team manager, arena/home ice and team notes.
- Active roster.
- Regular / Playoffs / Combined team skater and goalie statistics.
- Recent results and upcoming regular-season schedule.
- Team-specific transaction history and honors.

Retains v2.3.2 parser hardening and all existing league-management features.
